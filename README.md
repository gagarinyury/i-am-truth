# Я есть Правда / I Am Truth

Агент методологического аудита биомедицинских публикаций. Заявка на
Google **All Things Agentic Hackathon** (дедлайн 01.09.2026, 02:00 CEST).

**Тезис проекта, проверенный замером:** ценность не в критическом промпте — его
скопирует любой, — а в **принудительном вытягивании full-text и таблиц приложения**.
Одна и та же модель с одним и тем же промптом даёт 3.0/5 по голому абстракту и
4.0–4.5/5, когда ей подали таблицы приложения (F-13).

## С чего начать

```bash
bash scripts/preflight.sh     # проверка окружения: ADC, модели, целостность эталонов
```

Затем — `docs/00-INDEX.md`: карта документации и протокол работы (в проекте
параллельно работает больше одного агента).

## Структура

| Путь | Что там |
|---|---|
| `STATE.md` | Замысел, архитектура слоёв, найденные готовые кубики, ближайший шаг |
| `docs/01-requirements.md` | Требования хакатона и чеклист подачи |
| `docs/02-verified-facts.md` | Только проверенное — с датой, командой и источником |
| `docs/03-open-questions.md` | Вопросы со статусом и последствием для проекта |
| `docs/04-google-stack.md` | Что из стека Google уже готово и что подходит |
| `docs/05-decisions.md` | Журнал решений (ADR) |
| `eval/` | Харнес замеров, эталоны, входы, результаты прогонов |
| `scripts/preflight.sh` | Проверка окружения перед работой |

## Замер

```bash
python3 eval/harness.py run --models gemini-3.7-flash
python3 eval/harness.py report
```

Подробности методики и её ограничения — `eval/README.md`.

## Стек

- **Модель:** `gemini-3.7-flash` на Vertex AI (`merci-prod`, `global`, `v1beta1`).
  Pro-линейка на Vertex обрывается на 3.1 и не проходит порог правил «Gemini 3.5+».
- **Каркас:** `google-genai` 1.56.0 (входит в разрешённый список Google Agent Framework).
- **Инфраструктура:** не выбрана — см. открытые вопросы.
